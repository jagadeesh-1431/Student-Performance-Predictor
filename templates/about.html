System Architecture

EduPredict is a machine learning-based analytics platform designed to help educators identify students who may need additional support. By analyzing historical data and demographic factors, the system provides accurate predictions of academic outcomes.

The ML Pipeline

  • Pre-processing: Standard scaling and categorical encoding.
  • Dimensionality Reduction: PCA to handle multicollinearity.
  • Regression: Linear Regression for interpretable predictions.

Privacy First

All student data is anonymized and handled securely within the predictive engine.

Technology Stack

Python 3.10+ Flask (Backend) Scikit-Learn (ML) Chart.js (Visuals) Vanilla JS/CSS
